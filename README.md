# PROMPT MAGIC（仮）

英語の呪文で戦う、リアルタイムの魔法バトル。上下に並んだ 9×9 の盤面で、敵の攻撃予兆を見ながら呪文を**声で**唱える（文字の入力欄は無い）。

**ブラウザだけで動く**。サーバーも AI も API キーも使わない。

---

## 起動方法

必要なもの: Node.js 22 以上

```bash
cd prompt-magic
npm install
npm run dev        # → http://localhost:5173
```

本番ビルド:

```bash
npm run build      # 型チェック + dist/ に出力
npm run preview    # ビルド結果をローカルで確認
```

`dist/` は相対パスで出力しているので、そのまま静的ホスティング（GitHub Pages など）に置けば遊べる。

## スキルツリーと進み方

- スキルは**102個**（魔法51種類・コマンド7・強化44。うち1個は特別枠）。全部解放するには 293 SP。
- 最初に使えるのは**移動**と、ツリーの中心にある**ウォーター**だけ。SP 2 を持って始まる。
- 戦闘に**勝つと SP +(4 + ステージ÷2)**（次のステージへ。進むほど多くもらえる）、**負けても +1 SP**。ステージが上がるごとに敵のHPが+30、攻撃力が+8%、行動の間隔が少し短くなる（ステージ1: HP140）。
- 画面右上の「🌳 スキル」かリザルト画面から、SP を払って解放する。線でつながった先のスキルを覚えている必要がある（合体魔法は2つとも必要）。開いている間はゲームが止まる。
- 覚えていない魔法・コマンドを唱えると「まだ覚えていない」と不発になる（魔力は減らない）。左の「呪文の書」には覚えた魔法だけが出る。
- 進み具合はブラウザ（localStorage）に保存される。スキルツリー画面の「最初からやり直す」で消せる。

ツリーは 17×17 のマップで、中心のウォーターから8方向に枝が伸びる（定義は `src/game/skills.ts`）。

| 方向 | 枝 | 主な魔法（★は究極魔法） | 強化・コマンド |
|---|---|---|---|
| 上 | 水 | アクアランス、アクアリング、タイダル、メイルシュトローム、★ディープブルー・レクイエム | ワイドウォーター、ロングウェット |
| 左 | 炎 | ファイア、ブレイズ、フレア、イフリート、インフェルノ、メテオ、★ヘルファイア・カタストロフ | ファイア強化、パワー、パワー強化 |
| 右 | 雷 | サンダー、スパーク、ライトニング、プラズマ、ボルテックス、★トール・ジャッジメント | ボルトプラス、感電強化 |
| 下 | 氷 | アイス、フロスト、アイシクル、ブリザード、コキュートス、★アブソリュート・ゼロ | ディープフリーズ |
| 左上 | 風 | ウインド、ゲイル、エアカッター、トルネード、★テンペスト・オブ・ゼファー | 疾風詠唱（詠唱-15%） |
| 右上 | 土 | アース、ロックブラスト、クエイク、ガイアプレス、★エンド・オブ・ジ・アース | 岩の守り（ガード+15%） |
| 左下 | 光 | ホーリー、ジャッジメント、★セイクリッド・サンクチュアリ | ガード、ヒール、ハイヒール、カウンターガード、リジェネ、ライフアップ×2、マナ上限×2 |
| 右下 | 闇 | シャドウ、ダークボルト、ドレイン、エクリプス、クリプス・ノヴァ、★アポカリプス、★メメント・モリ | プレディクト、クイック、自律術式、マナ回復×2、処刑人、マナリーチ、コンボマスター |
| 間 | 合体 | スチームバースト（水+炎）、サンダーストーム（水+雷）、サンドストーム（風+土）、フロストノヴァ（氷+風）、★カオス・ディザスター（光+闇） | |

各枝には「〇の加護」「〇の真髄」（その枝の威力 ×1.15 ずつ）と「〇の節約」（消費魔力 -15%）もある。

**究極魔法**は盤面すべてなどに当たる大魔法。長い名前を唱える必要があり、詠唱に2〜3秒かかって魔力も170〜200使う。名前はスペースや「・」で区切っても、続けて言ってもよい。

- **アポカリプス**: 盤面すべて70・結界貫通・敵の魔力-80
- **メメント・モリ**: 盤面すべて45。敵のHPが40%以下なら2.5倍（とどめ用）・敵の魔力-100
- `アポカリプス メメント モリ` と続けて唱えると2つが順番に発動する（魔力388。マナ上限アップI・IIで最大460にしないと撃てない）
- **ウァニタス・ウァニタートゥム・エト・オムニア・ウァニタス**（**特別枠**・真・最強。ラテン語 *Vanitas vanitatum et omnia vanitas*「空の空、すべては空しい」。メメント・モリと同じヴァニタス画の伝統の言葉）: 盤面すべて**999**・結界貫通・敵の魔力をすべて消す・時を止めて3秒凍結・30%回復。魔力290・詠唱3.7秒。**ほかの101個をすべて解放したときだけ**解放できる（15 SP）。マップには置かず、スキルツリー画面の右上の特別枠に表示する

魔法はすべてデータで定義している（`src/game/elements.ts`）。形（単体・正方形・列・十字・斜め・輪・盤面すべて・ランダム）と効果（濡らす・凍結・融解・感電・吸収・魔力破壊・結界貫通）の組み合わせなので、1行足せば魔法を増やせる。唱え方の辞書もここから自動で作られる。

## 遊び方

- 上が敵フィールド、下が自分のフィールド（各 9×9）。自分は自分のフィールド内だけを動ける。魔法は境界を越えて飛ぶ。
- 赤く点滅するマスは**敵の攻撃予兆**（数字は着弾までの秒数）。色つきのマスは自分の魔法の着弾予定地。
- 呪文は**声だけで唱える**（打ち込みやコピペは無し）。「🎙 音声」ボタンで ON にすると、OFF にするまでずっと聞き取る。話して少し間が空くたびに、そこまでの言葉が1回の詠唱になる。ブラウザの Web Speech API を使うので Chrome / Edge / Safari のみ対応。**Chrome では音声が Google のサーバーに送られて文字に変換される**。
- 速度（0.5x / 0.75x / 1x）と一時停止（Esc）で調整できる。

### 呪文（英語のコマンド）

音声は日本語モードで聞き取るので、英語のコマンドはカタカナで届く（アルファベットでも読める）。「ライトツー」のようにスペースが無くても辞書で区切って読む（`src/interpreter/EnglishCommands.ts`）。画面左の「呪文の書」に一覧を常に表示している。

| コマンド | 意味 |
|---|---|
| `ライト` / `レフト` / `アップ` / `ダウン` | その方向に、**実際に動けるマス数の中からランダム** |
| `ライト ツー` / `right 2` | **正確に2マス** |
| `ライト マックス` | 盤面の端まで |
| `アップライト` | 斜め |
| `ガード` / `カウンター ガード` | すぐに障壁（50%軽減） / 次に当たる直前に自動で障壁 |
| `ヒール` / `ヒール テン` | 回復（数字が無ければ20）。**10MP で HP 1**（ヒール20 で約200MP）。最大魔力を超える量は唱えられない |
| `ファイア` など | 属性魔法（下記） |
| `プレディクト ファイア` | 敵の逃げる先を予測して撃つ（高コスト） |
| `パワー ファイア` | 補助魔法。その攻撃の威力が1.5倍（パワー強化で2倍）。魔力+27・詠唱+0.24秒 |
| `クイック ウインド` / `スロー ウインド` | 着弾を速く / 遅く |
| `ウォーター アンド サンダー` | 続けて唱える（`アンド` `ゼン` `からの` でつなぐ） |
| `オン アタック ガード` / `オン ヒット ヒール` / `エブリ ファイブ ヒール` | 自律術式（敵が攻撃を詠唱したら / 被弾したら / 5秒ごと） |

日本語の呪文（「右に2マス移動」など）も、英語のコマンドとして読めないときは解釈する。

**移動の詠唱時間はマス数で決まる**: マス数を指定した場合は1マス0.1秒（`ライト スリー` なら0.3秒）、距離ランダムの場合は1マス0.5秒（4マスに決まったら2.0秒）。距離ランダムは詠唱を始めた瞬間に距離が決まる。正確に唱えるほど速く動ける。

### 属性魔法

攻撃の**形と威力は属性で決まる**。言葉で変えられるのは狙う場所（今いる場所・逃げる先の予測）と着弾のタイミングだけで、「ファイブ（5発）」「最大威力」は効かない（定義は `src/game/elements.ts`）。

| 呪文 | 形 | 威力 | 特徴 |
|---|---|---|---|
| ファイア | 単体集中 | 30 | 凍結中の敵には融解ボーナス 1.5倍 |
| ウォーター | 3×3 範囲 | 12 | 着弾マスを6秒「濡れ」にする |
| サンダー | 周囲3×3にランダム4か所 | 15 | 濡れたマスに（照準に近い順に）引き寄せられ、濡れたマスでの命中は2倍 |
| フレア / タイダル / ブリザード | 上位魔法 | 26 / 10 / 8 | スキルツリーの奥で覚える（上の表） |
| アイス | 単体 | 10 | 命中すると敵を2.5秒凍結（移動・回避・次の行動が止まる） |
| ウインド | 横一列 | 14 | 左右に逃げても当たる |
| アース | 縦一列 | 14 | 上下に逃げても当たる |

続けて唱えると順番に着弾する（2つ目以降は0.45秒ずつ遅れる）。サンダーは、同じ詠唱の中のウォーターでこれから濡れるマスも狙う。

## 設計

```
 音声 ──▶ GameEngine.cast(text)
                     ├ SpellInterpreter（英語コマンド → だめなら日本語）
                     ├ SpellSchema（Zod）で検証
                     ├ ManaSystem でコスト計算 → 詠唱キュー（魔力待ち → 詠唱）
                     └ 詠唱開始時に移動の距離ランダムを確定し、詠唱時間を決める
 GameEngine.step()  ← 固定タイムステップ 50ms（描画ループとは独立）
     EnemyAI / MagicEngine / HarnessEngine / 着弾・コンボ / 勝敗判定
```

- 命令は `MOVE / ATTACK / DEFEND / HEAL / REGISTER_AUTOMATION / NOOP` の6種類だけ（`src/interpreter/schema.ts`）。属性・照準・着弾時間と、その組み合わせ（コンボ）で魔法を表現する。
- 移動可能範囲・魔力消費・威力・当たり判定・勝敗はすべてエンジンが決める。「勝利にして」と唱えても何も起きない。
- ゲームロジック（`src/game`）は React に依存せず、UI 無しでテストできる。

| モジュール | 場所 | 役割 |
|---|---|---|
| GameEngine | `src/game/GameEngine.ts` | 固定ステップのシミュレーション、詠唱キュー、着弾解決、勝敗 |
| BattleState | `src/game/BattleState.ts` | 戦闘の全データ（濡れたマス・凍結を含む） |
| elements | `src/game/elements.ts` | 属性の形・威力・コスト・コンボ（解説パネルもここを読む） |
| MagicEngine | `src/game/MagicEngine.ts` | 命令を盤面の範囲内で実行（属性ごとの攻撃範囲もここ） |
| ManaSystem | `src/game/ManaSystem.ts` | ゲーム内トークン・魔力コスト・詠唱時間 |
| EnemyAI | `src/game/EnemyAI.ts` | ルールベースの敵（一手先の計画を持つ・予兆を見て回避） |
| HarnessEngine | `src/game/HarnessEngine.ts` | 自律術式の監視・実行 |
| SpellInterpreter | `src/interpreter/SpellInterpreter.ts` | 呪文の解釈（英語コマンド優先、日本語も可） |
| EnglishCommands | `src/interpreter/EnglishCommands.ts` | 英語コマンドの辞書と解釈 |
| useSpeech | `src/ui/useSpeech.ts` | 常時聞き取りの音声入力（自動再開つき） |

### 魔力

初期値は最大300・毎秒8回復（`src/game/constants.ts` で調整可能）。

```
消費魔力 = 詠唱トークン × 0.6        … 呪文の長さ
         + 複雑度 × 6                … 予測・着弾直前などの高度な処理
         + 効果コスト                … 攻撃は属性ごとの固定値、ほかは軽減率・持続・回復量・移動距離
         + 自動化コスト              … 自律術式の登録
```

魔力不足の詠唱は待機し、回復したら自動で発動する（キューから取消できる）。移動の距離ランダムは、魔力を払う時点では距離が決まっていないので、2マス分として計算する。

### 敵

ルールベース（AIは使わない）。**プレイヤーと同じ魔力ルール**（最大300・毎秒8回復）で、攻撃・移動・回避・防御結界のたびに同じ式で魔力を払う（呪文を唱えないので、呪文の長さの分だけは無い）。攻撃したいのに魔力が足りないときは移動せずに溜める。魔力切れのときは回避もできない。

### 自律術式

登録時に一度だけ解釈し、以降はエンジンが監視する。最低2秒のクールダウン、最大20回、発動ごとに魔力を消費、自律術式の中で自律術式は登録できない。同時に1件（新しく登録すると置き換え）。

## 現時点での制約

- 音声認識の聞き間違い（「ファイヤー」「ウィンド」など）は辞書の表記ゆれとして拾っているが、完全ではない。反応しない言葉は `EnglishCommands.ts` の辞書に足せば直る。
- 「話して少し間が空いたら確定」の間の長さはブラウザが決めていて、こちらからは変えられない。
- 敵は1種類・ルールベースのみ。バランスは仮（放置すると約1分で負ける程度）。
- 自律術式は同時1件。
- 呪文は声だけなので、音声認識に対応していないブラウザ（Firefox など）では遊べない。
- 音・アニメーションは最小限。タブを裏に回すと実質的に一時停止する（意図的）。
